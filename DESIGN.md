# Vaishnavee Portfolio Design System

## Visual Identity
- **Vibe:** Premium editorial publication, contemporary literary journal, high-end creative studio
- **Keywords:** Black and white, premium, editorial, minimal, sophisticated, intelligent, literary, professional, human, quietly confident.

## Color Palette (Monochromatic)
- **Ink Black:** `#111111`
- **Deep Charcoal:** `#1C1C1C`
- **Warm White:** `#F7F6F2`
- **White:** `#FFFFFF`
- **Light Gray:** `#E9E8E4`
- **Border Gray:** `#D8D7D3`
- **Muted Gray:** `#777777`

## Typography
- **Display Typeface:** Playfair Display (or similar serif like Instrument Serif / Cormorant Garamond / DM Serif Display)
- **Body Typeface:** Inter (or similar clean modern sans-serif like Geist / Helvetica Neue)

## Layout & Composition
- **Whitespace:** Generous, editorial grid.
- **Asymmetry:** Encouraged for visual interest, avoid strict symmetry everywhere.
- **Lines & Borders:** Use thin rules (`1px` `#D8D7D3` or `#E9E8E4`) to separate content like in a magazine.

## Interaction Design
- **Subtle & Premium:** Gentle hover transitions, underline animations, project-row hover states, subtle scroll reveals.
- **Avoid:** Bouncing, parallax, gimmicks, excessive animations. Respect `prefers-reduced-motion`.

## UI Components
- **Buttons:** Sharp, minimal, maybe unrounded or slightly rounded (2px). Text with arrows (`→`).
- **Cards/Projects:** Not conventional grid cards. Think magazine spreads, rows with strong typography.
- **Navigation:** Sticky, extremely minimal.

## Content & Tone
- Short, confident sentences.
- Intelligent observations.
- Specificity.
- Editorial restraint.
